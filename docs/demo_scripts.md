# ContinuCare Demo 演示脚本

> 全程使用合成患者“陈女士（合成）”。本系统只提供连续照护工作流与证据整理，不提供诊断、治疗或用药建议。

## 60–90 秒版本

1. **0–10 秒：首页** — 指出“仅使用合成数据”、本地稳定演示、SQLite 与飞书 Mock 标签。点击“重置并载入 L2 工作流”。
2. **10–25 秒：患者页** — 展示“今天吐了一次，喝水也不太想喝。”及两个高亮证据；说明它们被保存为带字符位置的 Observation。
3. **25–45 秒：护士页** — 展示由确定性 `GLP1-002` 生成的 L2 Alert、24 小时 SLA 和明确标注的模拟飞书卡片。点击“确认收到”，填写“已完成合成演示复核”，再关闭。
4. **45–70 秒：医生页** — 生成 14 天简报，展开 Alert 条目的 Evidence，指出触发原因与最终处理记录都可回溯；点击“标记已审阅”，强调未写入 EMR。
5. **70–90 秒：审计页** — 展示患者提交、抽取、规则命中、Alert、Mock 通知、护士处理、摘要生成和医生审阅的时间链。

## 2–3 分钟版本

1. **安全与模式（20 秒）** — 首页说明合成数据、非诊断、非急救通道；外部 AI 和真实飞书均关闭，无 API Key 可运行。
2. **正常路径（25 秒）** — 一键载入“正常路径”。患者页展示恶心、正常饮水和“没有吐”；强调否定表达没有被抽取为呕吐阳性，护士页无 L2。
3. **L2 闭环（60 秒）** — 一键重置并载入 L2；患者页展开两个证据片段与结构化值；护士页解释纯规则 `vomiting_count >= 1 AND fluid_intake_reduced = true`，展示 SLA、Mock 卡片，完成确认和带记录关闭。
4. **医生证据简报（35 秒）** — 生成摘要，依次展示 Observation 趋势、Alert 触发与最终结果、缺失日期和医生待确认；展开 evidence_refs 并标记审阅。
5. **L4 安全路径（25 秒）** — 一键重置并载入 L4；患者页展示固定急救提示，不做疾病判断；护士页展示 `EMERGENCY-001`、L4 与值班角色。
6. **持久化与审计（15 秒）** — 刷新页面，说明数据仍在 SQLite；打开审计页，指出 Mock 通知从未被描述为真实飞书联调。

## 演示禁语

- 不说“系统诊断为……”；
- 不说“建议停药/改药/使用某治疗……”；
- 不说“飞书已经联调成功”或“这是大模型抽取结果”；
- 不引用真实患者、医院或评测数字。
