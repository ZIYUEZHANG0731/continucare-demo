# ContinuCare Demo 演示脚本

> 全程使用合成患者“陈女士（合成）”。本系统只提供连续照护工作流与证据整理，不提供诊断、治疗或用药建议。

## 60–90 秒版本

1. **0–10 秒：首页** — 先指向“最终要得到什么”：医生复诊前可直接审阅的证据简报。再说明患者 → 护士 → 医生如何形成闭环，点击“重置并载入 L2 工作流”。
2. **10–25 秒：患者页** — 先展示“本次随访产生了什么结果”、患者原话和下一步；再按需展开证据与结构化记录。
3. **25–45 秒：护士页** — 先展示“今天需要处理什么”和 24 小时内任务；说明进入队列的原因，完成确认并填写处理记录。模拟飞书卡片放在展开区且明确标注 Mock。
4. **45–70 秒：医生页** — 首屏用 30 秒简报展示“患者报告了什么、医护团队做了什么、复诊还要看什么”；再查看最终处理结果和证据链，点击“标记已审阅”，强调未写入 EMR。
5. **70–90 秒：证据链页** — 展示患者提交、证据形成、任务创建、护士处理、简报生成和医生审阅的六阶段业务时间线。

## 2–3 分钟版本

1. **安全与模式（20 秒）** — 首页说明合成数据、非诊断、非急救通道；外部 AI 和真实飞书均关闭，无 API Key 可运行。
2. **正常路径（25 秒）** — 一键载入“正常路径”。患者页直接显示“已记录，无需医护任务”和下一步；展开后可看到否定表达没有被记录为呕吐阳性。
3. **L2 闭环（60 秒）** — 一键重置并载入 L2；患者页先显示本次结果和下一步；护士页先显示待办任务及进入队列的原因，再按需查看纯规则 `vomiting_count >= 1 AND fluid_intake_reduced = true` 和 Mock 卡片，完成带记录关闭。
4. **医生证据简报（35 秒）** — 生成摘要，首屏依次展示患者报告、团队处理和复诊待确认；向下查看 Observation、Alert 最终结果、缺失日期和 evidence_refs，并标记审阅。
5. **L4 安全路径（25 秒）** — 一键重置并载入 L4；患者页展示固定急救提示，不做疾病判断；护士页展示 `EMERGENCY-001`、L4 与值班角色。
6. **持久化与审计（15 秒）** — 刷新页面，说明数据仍在 SQLite；打开审计页，指出 Mock 通知从未被描述为真实飞书联调。

## 演示禁语

- 不说“系统诊断为……”；
- 不说“建议停药/改药/使用某治疗……”；
- 不说“飞书已经联调成功”或“这是大模型抽取结果”；
- 不引用真实患者、医院或评测数字。
